# 游戏账号管理器

纯前端单文件 HTML 工具，用于管理多个游戏账号及其角色的日常打卡情况。无需后端、无需联网、无第三方依赖，双击即可在浏览器中使用。

## 功能特性

- **多账号 / 多角色**：每个账号可挂载最多 6 个角色，支持动态「增加 / 删除」角色
- **每日打卡**：每个角色每天可勾选「日常」与「押镖」
- **会员天数**：按天自动扣减，角色表格内显示剩余天数（绿 / 黄 / 红状态色）
- **活跃度**：与打卡联动（日常 +15、押镖 -50）
- **历史日期**：顶部日期可前后翻，查看任意一天的打卡情况
- **服务器筛选**：按服务器归集账号，下拉框每项显示该服务器下的账号数量
- **排序**：支持按「账号名称 / 添加先后 / 日常完成度」排序（默认按账号名称）
- **筛选**：支持「仅看未完成」「仅看完成」两种快捷筛选（互斥）
- **数据备份**：数据存于浏览器本地（localStorage），可通过「导入 / 导出 JSON」备份与恢复

## 使用方式

1. 双击 `index.html` 用浏览器打开即可使用
2. 账号数据保存在当前浏览器的本地存储中，**更换浏览器或清除缓存会导致数据丢失**
3. 建议定期使用「导出 JSON」功能备份数据；换设备时再用「导入 JSON」恢复

> 数据完全保存在你本地，不上传任何服务器。

## 技术说明

- 单文件 `index.html`，原生 HTML + CSS + JavaScript
- 数据持久化：`localStorage`
- 适配桌面与移动端（响应式布局）
